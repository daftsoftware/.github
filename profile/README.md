### Welcome
Hello! Glad you've landed here on the open source repositories for Daft Software! Hope you find something useful here for your projects.

### How can we help?
Daft Software is a UK based studio primarily specializing in C++ systems architecture and multiplayer that offers consulting on Unreal Engine projects. Feel free to get in touch at consulting@daftsoftware.com to find out how we can help you on your project.

### Repository Maintenance
Please note that there's no promise any of the open source repositories hosted here will be maintained indefinitely, generally they reflect what is currently used internally in Daft Software. If a plugin is actively being used then it's likely it will get updates, otherwise it will likely become archived when it's no longer actively maintained.
